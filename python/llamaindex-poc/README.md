# LlamaIndex PoC

## Introduction
LlamaIndex is a framework which is being used to develop llm applications based on RAG.

---

## Retrieval Augmented Generation
RAG is a framework which helps in improving llm responses by grounding them to an external knowledge base rather than 
staying dependent on static training data. It helps in curbing hallucinations and improving accuracy.
